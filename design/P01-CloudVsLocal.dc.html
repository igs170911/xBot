說明畫板 · PRD §16 電腦主機

地端主機 vs 你自己的雲端 Docker 主機

每個 Bot 都有一台自己的電腦（同一個 Docker 映像：Debian 桌面＋Chromium＋LibreOffice）。差別只在放在哪台主機：家裡這台，或你自己的 VPS、公司伺服器、另一台電腦。XBot 經 Tailscale 用 SSH 控制每台主機，不開公開埠。

不開任何公開埠

每台主機都在你的 tailnet

公網防火牆關掉 22 與所有 XBot 的埠；Tailscale ACL 只允許 XBot 服務節點連各主機的 22。

專用帳號 xbot

只放 XBot 的 SSH 公鑰。docker 群組等於 root，所以建議整台主機專給 XBot。

金鑰永遠留在 XBot 服務

遠端容器照舊連 product.sock，由 SSH 反向轉發回來；每個 Bot 的 worker key 驗證不變。

搬家

停止 → 經 SSH 打包 home／workspace／hermes → 在新主機還原，登入狀態跟著走。
