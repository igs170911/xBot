新增主機

把你自己的 VPS、公司伺服器或另一台電腦加進來，Bot 的電腦就能放在那裡。主機只經 Tailscale 連線，不開公開埠。

    2.

1 · 在要加入的主機上貼這一行

用 SSH 或主機商的網頁終端機登入那台 Linux 主機（Debian、Ubuntu 都可以），貼上後按 Enter。

$ curl -fsSL https://xbot.tail3f2a.ts.net/host/install.sh | sudo sh -s -- --token xbh_••••••••••••7Q2K
結尾是一次性代碼：只能用一次，用過就失效。
會安裝 Docker 與 Tailscale（已經有就略過），讓這台加入你的 tailnet。
建立專用的 xbot 帳號，只放 XBot 的 SSH 公鑰，不需要你的任何密碼。
不開任何公開埠：XBot 只經 Tailscale 用 SSH 連進來，Bot 的畫面埠只綁 127.0.0.1。
建議整台主機專給 XBot：xbot 在 docker 群組，等於有這台的最高權限。
等待主機連上…貼好指令後會自動進到下一步
