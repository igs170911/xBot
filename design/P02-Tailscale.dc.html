主機要開的兩個設定與權限

MagicDNS 與 HTTPS 憑證

在 Tailscale 管理後台的 DNS 頁打開這兩個，tailscale serve 才拿得到正式憑證。

MagicDNS用名字連主機，不用記 100.x 位址
HTTPS 憑證讓 *.ts.net 網址有正式憑證
XBot 網址https://xbot.<tailnet>.ts.net正式憑證
XBot 伺服器只綁 127.0.0.1，不開公開埠不用裝 CA
LazyBoy 現況

自簽憑證可以放進 Tailscale 的 100.x 位址（用 IP 走 HTTPS 可以），但 *.ts.net 名稱不行；所以 XBot 改用 tailscale serve 的正式憑證。

存取權限：Tailscale ACL

XBot 服務標 tag:xbot，只允許你自己的裝置連 443；每台 Docker 主機標 tag:xbot-host，只有 XBot 服務能連它的 22。其他人就算在同一個 tailnet 也連不到。

{
  "tagOwners": {
    "tag:xbot": ["me@example.com"], "tag:xbot-host": ["me@example.com"]
  },
  "acls": [
    // 只有你自己的裝置能連到 XBot 服務
    { "action": "accept", "src": ["me@example.com"], "dst": ["tag:xbot:443"] },
    // 只有 XBot 服務能 SSH 進每台 Docker 主機
    { "action": "accept", "src": ["tag:xbot"], "dst": ["tag:xbot-host:22"] }
  ]
}
你自己的雲端主機（例如 cloud-01）也是 tailnet 的成員：XBot 服務經 tailnet 用 SSH 控制每台主機的 Docker，不經公開網路。新手機要連：先在 Tailscale 登入同一個帳號，ACL 不用改。

斷線與備用方案

斷線時會怎樣

LazyBoy 現況XBot 沿用這些時間。工作在主機上跑：手機斷線、關掉網頁都不會中斷工作。
對話串流
SSE 每 10 秒送一次 keepalive；頁面隱藏時斷開，回來用 since 接續，不漏訊息。側欄每 5 秒、進度每 4 秒輪詢。
網路不通
網頁版只顯示提示，沒有離線聊天，也沒有推播。網路無法使用，請重新連線後再試
電腦畫面
斷線 8 秒後重試、冷卻 15 秒；20 秒沒連上判定失敗，連上 30 秒才算穩定；最多自動重試 2 次。切到背景 15 秒就暫停串流。畫面連不上，請按重新連線網路已離線，恢復後會自動重新連線
Bot 連線中斷
這次工作標記「已中斷」，不會自己重來。尚未完成的操作沒有自動重播

沒有 Tailscale：退回區網兩步 QR

LazyBoy 現況只在同一個區網內能用；在外面連請改用 Tailscale。
QR 1下載並信任 Local CA每台裝置一次。CA 有效 3650 天，名稱限制在私有網段。
QR 2直接登入https://<主機>:8791/#token=…
含登入碼，不要給別人看。
