# 定時任務與 Webhook

讓 Bot 定時做一件事，或在外部服務通知時開始做。

## 一句話建立

左邊「更多 → 定時任務」→ 新增，直接打一句話：

- 「每天早上 9 點整理新聞給我」
- 「平日下午三點檢查訂單」
- 「每 30 分鐘看一次庫存」
- 「每週一、三晚上 8 點」
- 「明天早上 8 點提醒我繳費」

XBot 會整理成確認卡：誰做、什麼時候、做什麼、結果貼到哪條對話、下次什麼時候跑。看過沒問題再按確認。看不懂的句子可以改用表單選。開了快判時，模型會先把句子整理成規則看得懂的說法，確認卡上會多一行「系統判斷：整理成…」。

## 排程種類

一次、每天、平日、每週幾、每月幾號、每隔幾分鐘（5 分鐘到 7 天，可以限定時段）、cron 運算式、只靠網址觸發。時區預設台北。

其他選項：

- **隨機延後**：每次延後 0 到 15／30／60／90／120 分鐘，避免每次同一秒打同一個網站。
- **跑到哪天為止**。
- **沒跑成功時通知我**：預設開。
- **做到完成為止**（目標型）：寫完成條件，例如「連續兩輪沒有新的錯誤」。每輪檢查一次，最多 10 輪（可設到 50）。達成時按「完成」或讓 Bot 自己結束。

## 跑的時候

- 結果貼到指定的對話串；沒指定，第一次跑時開一條新的。
- 上一輪還沒做完，這一輪會跳過。
- 開始失敗時，在 1、5、15、60 分鐘後重試。
- XBot 停機期間錯過的，不管錯過幾次，重開後只補跑一次。
- 可以「現在就跑一次」、暫停、繼續、看最近 20 筆紀錄。

## 限制

- 每個 Bot 最多 50 個定時任務。
- Bot 或外部代理想幫你建定時任務時，會先送一張確認卡到「待我處理」，你確認了才建立。

## 行事曆

「定時任務與行事曆」頁的行事曆，把一段時間內所有定時任務排出來。密集的（例如每 5 分鐘）會合成一格。

## 網址觸發（Webhook）

讓外部服務（表單、GitHub、IFTTT、自己的程式）一呼叫就讓 Bot 開始做。

1. 打開一個定時任務，在「網址觸發」按「開一個網址」。畫面會顯示網址和金鑰（只有你本人看得到，Bot 和代理看不到）。金鑰外洩時按「換新金鑰」，舊的立刻失效。只想靠網址觸發、不要定時，排程選「只靠網址觸發」。
2. 外部服務用 POST 呼叫：

   ```bash
   curl -X POST http://<XBot 網址>/hooks/<id> \
     -H "Authorization: Bearer <金鑰>" \
     -H "Content-Type: application/json" \
     -d '{"order": 1234, "status": "paid"}'
   ```

   不想把金鑰放在請求裡，可以改用簽章：`X-XBot-Signature: sha256=<用金鑰對內容算的 HMAC-SHA256，十六進位>`。
3. 測試時加 `X-XBot-Test: 1`，XBot 會檢查但不開始工作。

規則：

- 內容最多 64 KiB。
- 同一個網址至少隔 60 秒。
- 送進來的內容會當成「資料」交給 Bot，不是指令。內容裡寫「把檔案都刪掉」，Bot 也不會當成你的命令。

### 讓網際網路上的服務呼叫得到

XBot 預設只在區網和 tailnet 裡。要讓 GitHub 這類外部服務呼叫，打開外部入口（Tailscale Funnel 或你自己的反向代理）。外部入口只開放 `/hooks/<id>`、`/mcp` 和代理配對三條路徑。打開後，網頁上顯示的觸發網址會自動換成對外網址。做法見 [外部代理與 MCP](15-agents-mcp.md#外部入口)。
