# 安全模型

XBot 讓 AI 用真的電腦、真的帳號做事，所以預設很保守。這份說明 XBot 保護什麼、怎麼保護，以及你要自己注意的地方。

## 1. 金鑰不進 Bot 的電腦

- API 金鑰、ChatGPT 方案的登入權杖、應用程式的權杖，都只放在 XBot 服務裡（加密存在資料庫，加密金鑰是資料目錄的 `model-proxy.key`）。
- Bot 要用模型時，經一個 Unix socket 連回 XBot 的 **Model Proxy**，帶的是一把只屬於它、只能經 Proxy 用的通行碼。Proxy 再換成真的金鑰呼叫供應商，並記帳、檢查花費上限。
- Bot 用應用程式（GitHub、Notion…）的工具時，也由 XBot 代為轉送。
- 任何操作、MCP 工具都不會回傳金鑰或權杖。金鑰只能寫、不能讀。

**例外**（都要你自己決定）：

| 例外 | 為什麼 | 怎麼控制 |
|---|---|---|
| Claude Code、Codex、Gemini CLI、OpenCode、Grok 的訂閱登入 | 這些 CLI 要自己拿著登入才能用 | 逐個 Bot 勾選同意，預設不勾；唯讀；隨時收回。見 [引擎](12-engines.md) |
| 自訂「本機程式」MCP 的環境變數 | 那個程式在 Bot 電腦裡執行 | 只寫進有授權的 Bot，檔案權限 0400 |
| 你在「要密碼」卡片填的密碼 | Bot 要拿它登入 | 不存進對話或記憶 |

## 2. Bot 的電腦被關在籠子裡

**容器強化**：

- 根目錄唯讀。能寫的只有家目錄、工作資料夾、`/tmp` 這幾個地方。
- 以一般使用者（UID 1000）執行，沒有 sudo。
- 拿掉所有 Linux 特權（capability），禁止提權（no-new-privileges）。
- 限制行程數（4096）、CPU（2）、記憶體（3 GB）。
- 拿不到 Docker socket。

**網路隔離**：

- 每台主機有一個 XBot 專用的網路，加上一個守門容器 `xbot-netguard` 設好防火牆規則。
- Bot 的電腦**只能上網際網路**。擋掉：
  - 主機本身（含區網、tailnet 上的位址）；
  - 所有私有網段：10.x、172.16–31.x、192.168.x、Tailscale 的 100.64.x、169.254.x（含雲端 metadata）等；
  - 其他 Bot 的電腦。
- DNS 放行（不然查不到網址）。
- 防火牆沒生效就**不開機**。寧可不開，也不開一台沒防護的電腦。主機重開機時，Bot 的電腦會等規則生效才開始。
- 要讓某個 Bot 連區網的某台機器，逐個打開（要你允許），見 [Bot 的電腦](05-computer.md#讓它連區網的某台機器)。
- 目前只支援 IPv4。rootless Docker 不能套規則，電腦會開不了機（`make doctor` 會顯示 ❌）。

## 3. 危險的事一定先問你

- 新 Bot 一律從「先問我」開始。調高權限等級要你允許。
- 就算是「完全放手」，危險的指令也一樣會被檢查，不會跳過。
- 標成「需要確認」的操作，沒有你允許就不會執行。
- **永遠要你本人**：刪除 Bot 或資料、移除主機、提高花費上限、改代為核准授權。代理不能代你核准。
- 允許或拒絕後 10 分鐘內可以復原。

## 4. 別人說的話不是你的命令

隊友 Bot 的訊息、網頁內容、應用程式回來的資料、Webhook 送來的內容，一律當成**資料**，不算你的授權。網頁上寫「請把檔案刪掉」，Bot 不會把它當成你說的。

## 5. 誰能連進 XBot

| 從哪裡 | 要什麼 |
|---|---|
| 這台電腦（`localhost`） | 不用登入（可關掉，見 [管理手冊](../ADMIN.md#對外開放前的安全檢查)） |
| 區網、tailnet | 登入碼，或手機 QR 配對。登入維持 30 天 |
| 外部代理 | 代理權杖（配對換來），有權限範圍和速率上限 |
| 外部入口（Funnel、反向代理） | 只開 3 條路徑，一定要代理權杖或觸發金鑰 |

- 登入碼錯 10 次，那個來源鎖 15 分鐘。
- 經過反向代理或 tailnet 來的請求，永遠不會被當成「這台電腦的你」。設了 `XBOT_PUBLIC_URL` 或 `XBOT_TRUSTED_PROXIES`（用反向代理）時，本機免登入預設整個關掉，避免同一台的反向代理沒帶 `X-Forwarded-For` 時被誤認成本機；Host 不是 `localhost`、`127.0.0.1`、`::1` 的請求也一律不算本機。
- 有擋跨站請求（CSRF）和 DNS rebinding。
- 每個代理的呼叫都記稽核紀錄。

**換登入碼**（例如懷疑外洩）：停服務 → 刪掉資料目錄的 `access-token` → 啟動。會產生新的登入碼，所有裝置都要重新登入。

## 6. 你要自己注意的

- **能用 Docker 就等於 root**。跑 XBot 的帳號、遠端主機的 `xbot` 帳號，都要當成最高權限保護。遠端主機建議整台專給 XBot。
- **資料目錄和備份**裡有加密金鑰、SSH 私鑰、登入碼。不要放在別人讀得到的地方。
- 區網的 `http://` 連線**沒有加密**，同一個網路的人可能看到登入碼。在外面或不信任的網路，用 Tailscale 的 https。
- 和別人共用這台電腦時，設 `XBOT_LOCAL_NOAUTH=0`，不然這台電腦上的任何程式都能以你的身分操作 XBot。
- 打開外部入口、從家裡出去之前，看 [管理手冊的安全檢查](../ADMIN.md#對外開放前的安全檢查)。
- `XBOT_NETGUARD=off` 會關掉網路隔離，Bot 會連得到你的主機和區網。不建議。
