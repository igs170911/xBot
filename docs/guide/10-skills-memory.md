# 技能與記憶

在「Bot 設定 → 能力」管理（技能、記憶兩個分頁）。改了從下一個對話開始生效。

## 技能

技能是一份做法說明（`SKILL.md`）：什麼時候用、怎麼做。每次對話只帶上技能的名稱和用途，需要時 Bot 才讀完整步驟，所以多放幾個也不佔空間。

技能從哪來：

- **你寫**：「新增技能」，填名稱、什麼時候使用、怎麼做。
- **教它**：示範一次，自動整理成技能。見 [Bot 的電腦](05-computer.md#教它一件事)。
- **Bot 提議**：它做完一件以後還會再做的事，會把做法整理成提議，送到「待我處理」。你核准後才加進它的技能。
- **匯入**：`.md`（SKILL.md）或 `.zip`。匯入的技能一律先**停用**。先看內容（會列出要執行的指令和附帶的程式），沒問題再打開。
- **技能庫**：所有 Bot 共用的技能，在「設定 → 進階 → 技能庫與實驗」。從技能庫加到某個 Bot 後，各改各的，互不影響。內建 3 個從 LazyBoy 帶來的技能。

可以停用（先不用）或刪除（連附帶的檔案一起刪，不能復原，要你允許）。

每個技能下面會寫「最近 30 天用了 N 次 · M 次沒做完」。「沒做完」是那件工作最後被判定為只說要做、交回給你、卡住或出錯；停下來等你允許或回答的不算。同一個技能常常沒做完，「待我處理」會出現改這個技能的提議（見下面的「學到的事」）。

上限：名稱 64 字、用途 1,024 字、內容 100,000 字。

## 記憶

記憶是 Bot 跨對話記住的事，分兩份：

| 清單 | 記什麼 | 上限 |
|---|---|---|
| Bot 記住的事 | 工作上學到的：環境、做法、專案位置 | 2,200 字 |
| 關於你 | 你的習慣、偏好、常用資訊 | 1,375 字 |

- 每個對話串開始時載入一次。超過上限的部分不會帶進對話。
- Bot 會自己記，你也可以直接新增、修改、刪除。
- 寫入前會自動遮蔽密碼與金鑰。
- 快滿時會提醒你：刪掉過時的，或把幾條合成一條。
- 「最近的變更」可以看是誰（你、Bot、代理）改了什麼，並復原。修改會顯示「舊的 → 新的」；只調整順序的顯示「整理」。
- 不想讓它記：在 Bot 設定關掉記憶（下次開機生效）。

### 看它記了什麼、改掉記錯的

- **在對話裡**：Bot 記東西時，工作步驟會出現「記住了：…」（改掉或刪掉是「更新記憶」），旁邊有「看記憶」可以直接打開記憶頁。
- **在記憶頁**：每一條下面寫著來歷，例如「水哥哥 · 10/18 在「整理客戶名單」中記下」。點對話串的名字，可以回去看它是在什麼情況下記的。只保留最近 20 次變更的來歷，更早的不顯示。
- **改掉之後**：已經開著的對話串還是用舊的記憶。存好後提示裡有「開新對話串」，在新的對話串裡它才會用新的記憶。
- Bot 被交代不要把「工具做不到某事」記進記憶：工具會更新，記住這種結論會讓它一直拒絕你。如果還是記了，照上面刪掉就好。

## 學到的事

工作沒做完（只說要做、交回給你、卡住），或你在回覆上按「不對？」說它沒做完時，XBot 會請比較強的模型（老師）看一遍那次的步驟，提議一條以後照做的守則，送到「待我處理」：

- **加給這個 Bot**／**加給所有 Bot**：寫進守則，下一段新對話開始照做。
- **加進技能**：同一個技能常常沒做完時，提議會變成那個技能的注意事項，加在技能最後的「注意」段落。
- **改字**：先改成你要的說法再加。
- **不要**：略過。

在「能力 → 記憶」最上面的「學到的事」可以看全部、刪掉，或自己加一條。

- 每條 80 字內；給這個 Bot 的、給所有 Bot 的各最多 12 條。每條每次對話都會帶上，留真的有用的就好。
- 每個 Bot 一次只會有一張提議，每天最多 3 張。
- 老師用你接好的最好的模型（有 ChatGPT 方案時用它，否則用預設模型），花費記在用量裡。
- 所有引擎都會讀（Hermes、Claude Code、Codex 等）。

## 常駐指示與人設

「Bot 設定 → 基本」的人設（常駐指示），每次對話都會帶上。適合寫「說話簡短、先講結論」「花錢或對外發送前一定先問我」這類固定要求。

## 用其他引擎的 Bot

技能和記憶目前是給 Hermes 引擎用的（「學到的事」例外，所有引擎都會讀）。引擎換成 Claude Code、Codex、Gemini CLI、OpenCode、Grok 的 Bot，不會讀這裡的技能和記憶；它的記憶頁只會說明這件事，並提供「換引擎」。見 [引擎](12-engines.md)。
