# 技能與記憶

在「Bot 設定 → 能力」管理（技能、記憶兩個分頁）。改了從下一個對話開始生效。

## 技能

技能是一份做法說明（`SKILL.md`）：什麼時候用、怎麼做。每次對話只帶上技能的名稱和用途，需要時 Bot 才讀完整步驟，所以多放幾個也不佔空間。

技能從哪來：

- **你寫**：「新增技能」，填名稱、什麼時候使用、怎麼做。
- **教它**：示範一次，自動整理成技能。見 [Bot 的電腦](05-computer.md#教它一件事)。
- **Bot 提議**：它做完一件以後還會再做的事，會把做法整理成提議，送到「待我處理」。你核准後才加進它的技能。
- **匯入**：`.md`（SKILL.md）或 `.zip`。匯入的技能一律先**停用**。先看內容（會列出要執行的指令和附帶的程式），沒問題再打開。
- **技能庫**：所有 Bot 共用的技能，在「設定 → 進階 → 技能庫與實驗」。從技能庫加到某個 Bot 後，各改各的，互不影響。內建 3 個從 LazyBoy 帶來的技能。

可以停用（先不用）或刪除（連附帶的檔案一起刪，不能復原，要你允許）。

上限：名稱 64 字、用途 1,024 字、內容 100,000 字。

## 記憶

記憶是 Bot 跨對話記住的事，分兩份：

| 清單 | 記什麼 | 上限 |
|---|---|---|
| Bot 記住的事 | 工作上學到的：環境、做法、專案位置 | 2,200 字 |
| 關於你 | 你的習慣、偏好、常用資訊 | 1,375 字 |

- 每個對話開始時載入一次。超過上限的部分不會帶進對話。
- Bot 會自己記，你也可以直接新增、修改、刪除。
- 寫入前會自動遮蔽密碼與金鑰。
- 快滿時會提醒你：刪掉過時的，或把幾條合成一條。
- 「最近的變更」可以看是誰（你、Bot、代理）改了什麼，並復原。
- 不想讓它記：在 Bot 設定關掉記憶（下次開機生效）。

## 常駐指示與人設

「Bot 設定 → 基本」的人設（常駐指示），每次對話都會帶上。適合寫「說話簡短、先講結論」「花錢或對外發送前一定先問我」這類固定要求。

## 用其他引擎的 Bot

技能和記憶目前是給 Hermes 引擎用的。引擎換成 Claude Code、Codex、Gemini CLI、OpenCode、Grok 的 Bot，不會讀這裡的技能和記憶。見 [引擎](12-engines.md)。
