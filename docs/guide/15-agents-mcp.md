# 外部代理與 MCP

XBot 的每個功能都是一個「操作」，例如 `xbot.bots.create`、`xbot.chat.send`。同一份操作同時是網頁用的 API、MCP 工具和 `xbot` 指令。所以 Claude Code、Codex、Cursor 這類代理，能做的事和你在網頁上一樣多，也一樣要經過權限和核准。

完整的設定步驟（各種用戶端的設定檔、呼叫規則、錯誤格式）在 [把代理接上 XBot MCP](../mcp-setup.md)。這裡講重點。

## 配對：給代理一把權杖

1. 「設定 → 進階 → 外部代理與 MCP」→ 新增代理，選它能做什麼：

   | 權限 | 能做什麼 |
   |---|---|
   | 查看（read） | 讀 Bot、對話、狀態 |
   | 交辦（operate） | 對 Bot 說話、停止、回答 |
   | 管理（manage） | 建 Bot、改設定、團隊 |
   | 系統（admin） | 系統設定 |

   還可以限制它只能碰哪幾個 Bot、每分鐘最多幾次（預設 60）、權杖幾天後失效。預設它只能碰**自己建立的**東西。
2. 畫面給你一個配對碼（一次性、5 分鐘內有效）。
3. 在代理那台機器換權杖：

   ```bash
   XBOT_URL=http://<XBot 網址>:8780 xbot mcp pair <配對碼>
   ```

   權杖只顯示這一次，XBot 只存它的雜湊。
4. 接到代理，例如 Claude Code：

   ```bash
   claude mcp add --transport http xbot http://<XBot 網址>:8780/mcp \
     --header "Authorization: Bearer xbot_你的權杖"
   ```

只有你本人能產生配對碼、改代理權限。代理就算有「系統」權限也不行，也不能設模型金鑰。

指令列：`xbot agents pair_start --name "Claude Code" --scopes read --scopes operate`。

## 代理可以做什麼

- 建 Bot、交代工作、等結果：`xbot.chat.send` 收下就回，再用 `xbot.chat.wait_until_settled` 等它做完或需要人。
- 碰到要核准的事，會回 `pending_approval`，卡片出現在你的「待我處理」。代理用 `xbot.approvals.wait` 等，不要重送。
- 想讓代理在你不在時幫你允許某些事，見 [代為核准](04-inbox-approvals.md#代為核准讓代理幫你按允許)。

## 管理代理

同一頁可以看每個代理的權限、今天呼叫了幾次，改權限或撤銷。撤銷後下一個請求就被拒絕；10 分鐘內可以復原。

所有呼叫都記在稽核紀錄：誰、從哪裡、用了哪個工具、參數（密鑰遮蔽）、結果。網頁上，代理頁看得到每個代理最近做了什麼，Bot 設定「進階 → 歷史」看得到誰改了這個 Bot；完整紀錄在「設定 → 進階 → 成員與紀錄」，可以依誰、種類、結果、日期篩選（種類預設「只看變更」，查看類與標已讀、擷取畫面縮圖這類例行操作不列；選「全部，含查看」才看得到），指令列用 `xbot audit list`（`--actor`、`--op xbot.bots`、`--status error`、`--since`）。代理只看得到自己的紀錄。

任何工具都不會回傳金鑰或權杖。

## 外部入口

預設只有區網和 tailnet 連得到 XBot。代理不在你的 tailnet 裡（例如雲端上的服務）時，可以打開外部入口：

- **Tailscale Funnel**：先打開內建 Tailscale（見 [手機](14-phone.md)），再到「設定 → 進階 → 網路與 Tailscale」打開外部入口。要你本人允許。Tailscale 的存取規則要允許這台用 Funnel。
- **你自己的反向代理**（nginx、Caddy、Cloudflare Tunnel…）：設 `XBOT_PUBLIC_URL`，見 [管理手冊](../ADMIN.md#對外開放前的安全檢查)。

外部入口**只開放三條路徑**，其他（網頁、對話、事件、模型代理）一律 404：

| 路徑 | 驗證 |
|---|---|
| `/mcp` | 每個請求都要代理權杖；不收登入碼、不認 cookie |
| `/api/v1/agents.pair` | 一次性配對碼 |
| `/hooks/<id>` | 定時任務的網址觸發金鑰或簽章 |

速率上限比較嚴：每個來源 IP 每分鐘 120 個請求；每個代理經外部入口每分鐘 20 次呼叫。可以只允許某些 IP。

## Bot 自己用的 MCP

Bot 在自己的電腦裡也接著 XBot MCP，但只看得到給 Bot 用的一小組工具（約 40 個）：傳話給隊友、開群組、改自己所在的群組、發卡片給你、請你核准、請你接手、提案、記一件事、提議技能、排定時任務（要你確認）、看自己的檔案等。有團隊管理權限的 Bot 另外看得到管理團隊的工具（建團隊、調整隊友、換隊友的模型或權限要你按允許、看下屬的檔案）。管理類的工具（模型金鑰、主機、代理、刪除 Bot）它看不到。它的身分由連線決定，不能冒充別的 Bot。隊友的訊息和網頁內容一律當資料，不算你的授權。
