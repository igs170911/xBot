# Bot 與對話

## 建一個 Bot

頭像顏色可以從 10 個顏色選，或按最後一顆彩色的圓自己挑任何顏色。對話裡 Bot 的回覆氣泡會帶一點它的顏色。

左邊的「＋ 新增 Bot」。填名字和職稱就能建。不知道怎麼寫，按「幫我想名字和職稱」，或直接選範本。

- 新 Bot 的權限等級一律是「先問我」。
- 它的電腦在第一次對話時才開機。
- 全部最多 200 個 Bot（可在「設定 → 進階 → 限制」調）。

## 側欄

側欄只放常用的：

- 最上面是大總管（主要 Bot）的大卡片，點了就跟它說話。要換人當大總管：在那個 Bot 的選單（「⋯」或右鍵）選「設成大總管」，同時只有一個。下面兩顆小按鈕：「待我處理」（有數字表示有幾件等你）和「辦公室」。
- 其他 Bot 照團隊分區，一列一個：名字、職稱、最後一句話。有事時那一行會改成「等你回覆」「工作中…」；藍點表示有你還沒看的回覆。群組在最後。
- 右上的放大鏡可以搜尋 Bot 和群組；＋可以新增 Bot、新增群組、建立團隊。
- 左下角的齒輪是「設定與更多」：設定，以及不常用的頁面（定時任務、提案與討論、全部檔案、分享登入、團隊地圖、組織架構）、全部停下。旁邊是「連接應用程式」。

桌面的設定是跳出來的視窗，按 ✕、Esc 或點外面就回到原本的頁面。視窗比較窄（例如平板）時，設定的分類收在視窗上面一排。

側欄的寬度可以拖它的右邊緣調整（也能用方向鍵，雙擊回到預設），記在這個瀏覽器。嫌側欄太寬，也可以按左上的 ⊟ 縮成只有圖示，滑過圖示會顯示名字；再按一次展開。這個設定記在你這個瀏覽器。

每一列的選單：電腦上滑鼠移過去，右邊會出現「⋯」（按右鍵也可以）；手機長按一下，團隊名稱旁邊也有「⋯」。Bot 可以開對話、到 Bot 設定、移到別的團隊或移出團隊、刪除；群組可以改名換成員、刪除；團隊可以改名換成員、看團隊地圖、刪除。刪除都會先問你一次。

電腦上也可以直接用拖的：把 Bot 拖到另一個團隊的分區就換過去，拖到群組上就加進那個群組；沒有「未分區」時，拖的時候最下面會出現「拖到這裡＝移出團隊」。

## 交代工作

點左邊的 Bot，在下面輸入框說你要它做什麼，按 Enter 送出（用注音、倉頡選字時按 Enter 不會送出）。

- 回覆會即時出現。工作中的「思考中」預設收合，只露出最新一步，點開看全部；做完收成一行「工作了 N 分鐘 · M 步」。
- Bot 記住一件事時，步驟寫「記住了：…」或「更新記憶」，旁邊的「看記憶」可以檢查、改掉記錯的。見 [技能與記憶](10-skills-memory.md#看它記了什麼改掉記錯的)。
- 要給它檔案：按輸入框左邊的 ＋、把檔案拖進對話，或直接貼上截圖。像一般聊天軟體一樣，圖片直接顯示在對話裡，其他檔案是一張有圖示和檔名的小卡，點了打開、右邊可以下載。一則最多 10 個。也可以從它的檔案頁上傳，見 [檔案](09-files.md)。
- 它做出來的檔案也一樣：回覆裡只寫檔名（點了打開），回覆下面有那個檔案（圖片直接顯示、其他是檔案卡），不用看路徑。
- **網頁和儀表板**：請它「做一個儀表板」「做成網頁」，它會寫成一個網頁檔，直接在對話裡打開，圖表、按鈕都能用。右上的 ⤢ 放大，點檔名看原始碼，⬇ 下載。手機上對話裡只顯示預覽（手指滑過去捲的是對話），點一下放大再操作。網頁關在獨立的沙盒裡：讀不到你的登入、碰不到 XBot 和你家裡的網路，只能連外面的網站（例如畫圖表用的程式庫）。超過 1 MB 的網頁要下載後開。
- 傳圖片（截圖、照片）：Bot 的模型看得懂圖片（例：GPT、Claude、Gemini、Grok）就直接看；看不懂的（例：deepseek），XBot 會請你已經設定的另一個看得懂圖片的模型先描述給它，ChatGPT 方案優先（不另外花錢）。一個都沒有時，Bot 會直接說它看不到圖片。
- 想知道它做到哪：右上「更多」→「目前進度」。
- 想看或改它記得的事：右上「更多」→「記憶」。
- Bot 之間互相交辦的訊息在對話裡只顯示一行，點開看全文。
- 「更多」或側欄最下面的「⋯」→「全部停下」：緊急停止按鈕。所有 Bot 馬上停下正在做和排隊的工作，停的那幾秒 Bot 之間不會再互相叫醒。停完就照常，不用按「繼續」：之後你或 Bot 再交代的事都照常做。
- Bot 正在做事時也可以再傳：你的訊息會排隊，手上這件做完就接著做（排在隊友交辦、群組的事前面）。想讓它馬上改做別的，先按停止。
- 你接手它的電腦時，它會暫停；這時送的訊息會排隊，輸入框上方會提醒你，按「交還電腦」就開始。
- 它問你問題時，問題會同時出現在對話裡和「待我處理」，在哪邊回答都可以。
- 回覆裡的檔案路徑（`/workspace/…`）可以直接點開。手機的對話頁首也有檔案按鈕。
- 手機：點頭像看 Bot 的資料與設定；點中間的「名字 · 對話串」切換、新增、刪除對話串，也在那裡看目前進度。
- 它工作中你再送的訊息，會等這一輪做完才送出。要它改做別的事，先按 ■ 停止。停止時做到一半的檔案會保留。
- XBot 更新或重開時正在做的事，起來後會自動接著做一次，對話裡多一行「服務剛重開，接著做」。又被打斷時會顯示「做到一半被中斷了」，按「接著做」請它從做到的地方繼續。
- 想開新話題：標題下拉 →「新對話串」。同一個選單可以切換舊的對話串。
- 不要的對話串：打開標題下拉（手機是「對話串」），每一條右邊都有垃圾桶，直接按就能刪，不用先切過去（電腦上滑鼠移到那一條才出現）。正在看的這條也可以從「更多」→「刪除這個對話串」。確認視窗會寫出要刪的是哪一條。刪掉正在看的那條，會換到最近的另一條。訊息刪了無法復原；Bot 的電腦、檔案、記憶不受影響。Bot 正在這條對話串做事時要先停止。
- 打 `/plan`（或 `/規劃`）＋要做的事：Bot 會先把它拆成步驟計畫給你確認，你回「開始」之前不會動手、也不會交辦隊友或建 Bot。大工作建議都先這樣。你直接叫它建 Bot、建團隊或交給某位隊友時，它會一次做完整（成員、人設、報告線、群組一起建好）；只有它自己想找隊友分工時，才先列計畫問你。
- 輸入框開頭打 `/` 會列出這個 Bot 的技能（技能清單和技能庫），方向鍵選、Enter 或點一下帶入，後面接著寫要做的事。送出時會變成「使用技能「名稱」：…」，所有引擎都看得懂。
- 對話頁上面只留常用的：對話串、檔案、電腦。換這個 Bot 用的模型、和它通話，在右上的「⋯」裡（「模型：」那一項會寫出現在用的模型）。列出的是它目前方案能用的：用 API 金鑰的列出探測到的模型；用訂閱的列出那個 CLI 回報的模型（聊過一次之後才有）。
- 滑過訊息會出現複製、原始內容、唸出來和時間，排在訊息下面，不會蓋住下一則。

## 它怎麼跟你說話

Bot 回你的時候，像一個懂行的朋友在通訊軟體裡回訊息：口語、句子接得順，不是電報或報告。長短看你要拿這則回覆做什麼，不看它做了多少事：

| 你問的 | 它怎麼回 |
|---|---|
| 閒聊、打招呼 | 一兩句 |
| 簡單問題、問事實 | 第一句就是答案，三到五句，要出處的附連結 |
| 問建議、要它比較 | 先說它選哪個、為什麼，再一兩句講其他選項差在哪 |
| 要它研究、調查、規劃、設計 | 先真的查過幾個來源，對話裡給結論和骨架（誰做什麼、順序、關鍵數字），一個手機畫面看得完；細節和來源放檔案 |
| 交代的工作做完 | 一句說好了沒、東西在哪，再補沒做到的或有風險的 |
| 問進度 | 一兩句：做到哪、卡在哪、還要多久 |

- 要你決定的事：回覆短的話放最後一句；比較長的就放第一段，附選項和它的建議，不會埋在最後。
- 它自己能決定、做得到的就直接做完，再說一句做了什麼，不會一步一步問「要我…嗎」。只有花錢、對外發送、刪除，或有幾條路而選錯很難回頭時才先問你。
- 沒做完、沒查到、有風險，或它替你做了什麼判斷，才會提；沒有就不講。

上面這些沒有的就不講。過程不會寫在回覆裡，想看的話點回覆上面的「工作了 N 秒 · M 步」。

要不要存成檔案，看你之後會不會再用：只看一次的（結果、短清單、小表格、連結）直接寫在對話裡；會留著、會改、會分享的成品（報告、試算表、文件、程式），或一個畫面看不完的，存成檔案，回覆裡只講重點和路徑。中途抓的網頁、下載的原始資料放在 Bot 電腦的 /workspace/tmp/，過幾天會自動清掉。

一則回覆會照段落分成幾個連著的泡泡，表格、程式碼、清單不會被切開。講流程時，「選題 → 寫稿 → 發文」這種一行步驟會畫成方塊和箭頭；有分支的流程圖（mermaid）會畫成圖，按「原始碼」可以看它寫了什麼。複製、唸出來還是整則一起。很長的回覆會先收起來，按「顯示全部」展開。群組也一樣。

長短可以在「設定 › 一般 › 回話風格」調：

- **簡短**（預設）：照上面那張表，簡單問題三到五句。
- **一般**：簡單問題兩到四段，每段兩三句。
- **詳細**：可以完整說明，還是先講結果。

它會自己判斷要不要上網查：答案會變的（價格、新聞、天氣、營業時間、規格、法規）、要精確數字或出處的、它沒把握的，先查再回並附上來源；一般常識、意見、閒聊就直接回。

所有 Bot 都一樣，改了以後下一段新對話開始生效。Bot 之間交辦、回覆不照這個：交回給主管或隊友的寫結論、關鍵數字和檔案路徑，十行內，長的資料放檔案。主管收到隊友的成果，沒有具體疑點就採用，不會自己再查一遍；要改的意見一次寫齊，一輪只出一個新版本。

回話風格和其他基本守則是內建的，不用寫進人設。Bot 設定裡的「它做什麼」和「人設」只寫這個 Bot 自己的專長和個性。新對話的開場只會打一聲招呼，介紹和人設到 Bot 設定看、改。第一次和某個 Bot 聊時，下面還有「想先請它做什麼？」三個建議，之後開新對話就不再出現。

## 它什麼時候算做完

XBot 會看 Bot 最後的回覆判斷結果：

| 判斷 | 意思 | XBot 會做什麼 |
|---|---|---|
| 完成 | 有回答或成果 | 通知你 |
| 要人 | 它需要你給資料、登入、做決定 | 進「待我處理」 |
| 交回 | 它說做不下去交還給你，或你已經交代了，它卻在最後問「要我…嗎」 | 你交代的事：自動請它照交代的做完 |
| 只承諾沒做 | 說「我來處理」卻沒有動作；或你要它研究，它沒真的查資料就回了 | 自動請它繼續（說清楚哪裡沒做到） |
| 卡住 | 15 分鐘沒動靜（在跑工具時 40 分鐘） | 停下來通知你 |
| 額度用完 | 訂閱或 API 額度用完、限速 | 出「額度用完」卡，可以一鍵換引擎，見 [引擎](12-engines.md#額度用完) |

自動請它繼續最多 5 次（「設定 › 進階 › 限制」可以調）。你說「先不要做」「先討論」，或只是打招呼、問問題時，不會被當成沒做完。開了快速判斷時，模型也會看你原本怎麼交代的，只在你交代工作的第一輪、規則判「完成」時再確認一次，而且只能改成更嚴（例如「交回」），不會把沒做完的改成完成。

判斷是「完成」時不另外標示（這是常態）。其他判斷會在回覆下面標一顆小標籤，例如「需要你」，旁邊有「不對？」可以改正。

模型供應商暫時出錯時，XBot 會在 2、10、30 分鐘後各重試一次。

## 先判斷（選用）

開了快速判斷後，你送出訊息時，下面會出現幾顆小膠囊，例如「夠清楚」「不用開電腦 · 先查網路」「預估 小」。它們只是建議，不會改變 Bot 做什麼。不對就按「不對？」。設定見 [模型與花費](11-models-spend.md#快速判斷)。

## 權限等級

在「Bot 設定 → 權限與花費」改。

| 等級 | Bot 自己做 | 一定先問你 |
|---|---|---|
| 先問我（預設） | 讀東西、查資料 | 花錢、對外發送、改檔案、刪除 |
| 一般的事自己做 | 讀檔、改檔 | 其他會改東西的事 |
| 放手做 | 大部分 | 付款、簽約、上架 |
| 完全放手 | 幾乎都自己做 | 危險指令仍會擋下 |

- 改成「先問我」以外的等級，要你在「待我處理」允許。
- 就算「完全放手」，危險的指令也不會跳過檢查。
- 改了以後，下次電腦重開才生效。

## Bot 設定

對話右上「更多」→「Bot 設定」。左上的「回到對話」回到原本的對話；從「設定 → AI 模型」的 Bot 清單點進來的，會直接開「進階」的引擎與模型，左上回到「AI 模型」。分成幾頁：

- **基本**：名字、職稱、說明、人設（常駐指示）、外觀（顏色、10 種形狀、眼睛，或上傳頭像裁切）。
- **能力**：技能、記憶、應用程式與電腦（可以用哪些應用程式、在哪台主機跑）。見 [技能與記憶](10-skills-memory.md)。
- **權限與花費**：權限等級、花費上限、可以找誰（團隊管理權限在「組織架構」頁）。
- **進階**：AI 帳號與模型、思考強度（低／中／高，每個引擎都有效，改了下一則就生效；對話頁「⋯」→「模型」也能改）、歷史（設定的變更：誰改了什麼）。

## 封存、刪除、分享

- **封存**：先收起來，不出現在清單，也不能對話。正在做的事會先停下。資料都保留，隨時能取消封存。
- **刪除**：側欄的 Bot 上按右鍵（手機長按）→「刪除 Bot」。連同它的電腦（含檔案）、對話、任務一起刪，不能復原。你本人在畫面上按確認就會刪；Bot 或代理發起的刪除，一定要你本人在「待我處理」或對話裡按允許，不能代你核准。
- **分享成 .xbot 檔**：把設定、人設、技能做成一個檔案給別人。**不含**金鑰、登入資料、對話、記憶、電腦裡的檔案。匯入的 Bot 一律從「先問我」開始，帶進來的技能放到技能庫且先關閉。

## Bot 會自己建 Bot 嗎

會，但有限制：缺某種專長、你也同意時才建，一次一個；每 24 小時最多 3 個（有團隊管理權限的 20 個）。
