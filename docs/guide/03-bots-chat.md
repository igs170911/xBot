# Bot 與對話

## 建一個 Bot

頭像顏色可以從 10 個顏色選，或按最後一顆彩色的圓自己挑任何顏色。對話裡 Bot 的回覆氣泡會帶一點它的顏色。

左邊的「＋ 新增 Bot」。填名字和職稱就能建。不知道怎麼寫，按「幫我想名字和職稱」，或直接選範本。

- 新 Bot 的權限等級一律是「先問我」。
- 它的電腦在第一次對話時才開機。
- 全部最多 50 個 Bot。

## 側欄

左邊只放常用的：新增 Bot、待我處理、辦公室、你的 Bot 和群組。其他頁面（定時任務、提案與討論、全部檔案、分享登入、連接應用程式、團隊地圖、組織架構）收在最下面的「⋯」。

最下面是「設定」，旁邊的「⋯」打開其他頁面。桌面的設定是跳出來的視窗，按 ✕、Esc 或點外面就回到原本的頁面。

嫌側欄太寬，按右上的 ⊟ 縮成只有圖示，滑過圖示會顯示名字；再按一次展開。這個設定記在你這個瀏覽器。

## 交代工作

點左邊的 Bot，在下面輸入框說你要它做什麼，按 Enter 送出（用注音、倉頡選字時按 Enter 不會送出）。

- 回覆會即時出現。做事的步驟會收成一行「工作了 N 分鐘 · M 步」，點開看每一步用了什麼工具。
- 要給它檔案：按輸入框左邊的 ＋、把檔案拖進對話，或直接貼上截圖。檔案會先傳到它電腦的 `/workspace/uploads`，送出時訊息後面會附上路徑（「附件：/workspace/uploads/報價單.pdf」），它就知道去哪裡讀。一則最多 10 個。也可以從它的檔案頁上傳，見 [檔案](09-files.md)。
- 想知道它做到哪：右上「更多」→「目前進度」。
- 你接手它的電腦時，它會暫停；這時送的訊息會排隊，輸入框上方會提醒你，按「交還電腦」就開始。
- 它問你問題時，問題會同時出現在對話裡和「待我處理」，在哪邊回答都可以。
- 回覆裡的檔案路徑（`/workspace/…`）可以直接點開。手機的對話頁首也有檔案按鈕。
- 手機：點頭像看 Bot 的資料與設定；點中間的「名字 · 對話串」切換、新增、刪除對話串，也在那裡看目前進度。
- 它工作中你再送的訊息，會等這一輪做完才送出。要它改做別的事，先按 ■ 停止。停止時做到一半的檔案會保留。
- 想開新話題：「更多」→「新對話串」。標題下拉可以切換舊的對話串。
- 不要的對話串：標題下拉或「更多」→「刪除這個對話串」。訊息刪了無法復原；Bot 的電腦、檔案、記憶不受影響。Bot 正在這條對話串做事時要先停止。
- 輸入框開頭打 `/` 會列出這個 Bot 的技能（技能清單和技能庫），方向鍵選、Enter 或點一下帶入，後面接著寫要做的事。送出時會變成「使用技能「名稱」：…」，所有引擎都看得懂。
- 對話右上的模型名稱可以換這個 Bot 用的模型。列出的是它目前方案能用的：用 API 金鑰的列出探測到的模型；用訂閱的列出那個 CLI 回報的模型（聊過一次之後才有）。
- 滑過訊息會出現複製、原始內容、唸出來和時間，排在訊息下面，不會蓋住下一則。

## 它什麼時候算做完

XBot 會看 Bot 最後的回覆判斷結果：

| 判斷 | 意思 | XBot 會做什麼 |
|---|---|---|
| 完成 | 有回答或成果 | 通知你 |
| 要人 | 它需要你給資料、登入、做決定 | 進「待我處理」 |
| 交回 | 它說做不下去，交還給你 | 通知你 |
| 只承諾沒做 | 說「我來處理」卻沒有動作 | 自動請它繼續，最多 2 次 |
| 卡住 | 15 分鐘沒動靜（在跑工具時 40 分鐘） | 停下來通知你 |
| 額度用完 | 訂閱或 API 額度用完、限速 | 出「額度用完」卡，可以一鍵換引擎，見 [引擎](12-engines.md#額度用完) |

判斷是「完成」時不另外標示（這是常態）。其他判斷會在回覆下面標一顆小標籤，例如「需要你」，旁邊有「不對？」可以改正。

模型供應商暫時出錯時，XBot 會在 2、10、30 分鐘後各重試一次。

## 先判斷（選用）

開了快判後，你送出訊息時，下面會出現幾顆小膠囊，例如「夠清楚」「不用開電腦 · 先查網路」「預估 小」。它們只是建議，不會改變 Bot 做什麼。不對就按「不對？」。設定見 [模型與花費](11-models-spend.md#快判)。

## 權限等級

在「Bot 設定 → 權限與花費」改。

| 等級 | Bot 自己做 | 一定先問你 |
|---|---|---|
| 先問我（預設） | 讀東西、查資料 | 花錢、對外發送、改檔案、刪除 |
| 一般的事自己做 | 讀檔、改檔 | 其他會改東西的事 |
| 放手做 | 大部分 | 付款、簽約、上架 |
| 完全放手 | 幾乎都自己做 | 危險指令仍會擋下 |

- 改成「先問我」以外的等級，要你在「待我處理」允許。
- 就算「完全放手」，危險的指令也不會跳過檢查。
- 改了以後，下次電腦重開才生效。

## Bot 設定

對話右上「更多」→「Bot 設定」。分成幾頁：

- **基本**：名字、職稱、說明、人設（常駐指示）、外觀（顏色、10 種形狀、眼睛，或上傳頭像裁切）。
- **能力**：技能、記憶、應用程式與電腦（可以用哪些應用程式、在哪台主機跑）。見 [技能與記憶](10-skills-memory.md)。
- **權限與花費**：權限等級、花費上限、可以找誰（團隊管理權限在「組織架構」頁）。
- **進階**：引擎與模型（備援模型、思考強度低／中／高）、歷史（設定的變更：誰改了什麼）。

## 封存、刪除、分享

- **封存**：先收起來，不出現在清單，也不能對話。正在做的事會先停下。資料都保留，隨時能取消封存。
- **刪除**：連同它的電腦（含檔案）、對話、任務一起刪，不能復原。一定要你本人在「待我處理」允許，代理不能代你核准。
- **分享成 .xbot 檔**：把設定、人設、技能做成一個檔案給別人。**不含**金鑰、登入資料、對話、記憶、電腦裡的檔案。匯入的 Bot 一律從「先問我」開始，帶進來的技能放到技能庫且先關閉。

## Bot 會自己建 Bot 嗎

會，但有限制：缺某種專長、你也同意時才建，一次一個；每 24 小時最多 3 個（有團隊管理權限的 20 個）。
