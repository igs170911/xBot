# 第一次使用

裝好後打開 http://127.0.0.1:8780 。還沒有任何 Bot 時，會出現兩步的首次設定。

## 第 1 步：接上 AI

Bot 要有一個 AI 才能工作。挑一個就好，之後可以再加。

- **這台電腦已登入的訂閱**：XBot 會找出已登入的 Claude Code、Codex CLI，列成選項。
- **本機模型**：偵測到 LM Studio 或 Ollama 時會列出來。速度看這台電腦。
- **API 金鑰**：按「改用 API 金鑰」，選供應商（OpenAI、Anthropic、OpenRouter、OpenCode Go…），貼上金鑰。金鑰只存在這台主機，不會進 Bot 的電腦。

ChatGPT 方案（Plus／Pro／Business）也能直接登入使用，在「設定 → AI 模型」，見 [模型與花費](11-models-spend.md)。

## 第 2 步：認識小秘

XBot 幫你建第一個 Bot「小秘」（幕僚長）。你可以：

- 換頭像的顏色和眼睛（只有眼睛、沒有嘴巴）。之後在外觀還能換 10 種形狀。
- 看它的權限等級：**先問我**。付款、對外發送、刪除這類事，做之前一定先問你。之後可以改。

第 1 步選了訂閱（例如 Claude）時，這裡會多一個勾選框「我同意讓小秘使用我的 Claude 訂閱」，**預設不勾**。勾了，這台電腦上的登入憑證會唯讀放進小秘的電腦，只有它拿得到，也會用掉你的方案額度。不勾也可以，小秘會改用你設定好的模型。詳細見 [引擎](12-engines.md)。

做完會跳出 3 站的導覽。之後想再看：對話右上的「更多」→「看導覽」。

## 首頁

首頁是「待我處理」，所有要你決定的事都在這裡。首頁上有幾張「之後再做」卡片，可以跳過：

- **連手機**：掃 QR 在手機上登入。見 [手機](14-phone.md)。
- **導覽**

跳過的事都找得到：連手機在「設定 → 電腦與裝置」。

## 接下來

1. 在左邊點「小秘」，對它說一件事，例如「幫我比較三家咖啡豆的價格」。
2. 第一次對話時，它的電腦會開機（約半分鐘）。之後閒置 30 分鐘會休眠，有工作會自己醒來。
3. 它要做需要你同意的事時，對話裡和「待我處理」都會出現卡片。

更多：[Bot 與對話](03-bots-chat.md)、[待我處理與核准](04-inbox-approvals.md)。

## 沒有 Bot 時

把所有 Bot 刪掉或封存後，首頁會變成「建立第一個 Bot」：一句話說你要它做什麼，或從範本（選品研究員、社群小編、帳房、數據分析師…）點一下建立。
