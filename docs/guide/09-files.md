# 檔案

Bot 做出來的東西都在它電腦的 `/workspace` 裡。你不用打開它的電腦就能看、下載、上傳。

## 在哪裡看

- **全部檔案**（左邊）：每個 Bot 的成果、你上傳的、示範教學、從隊友來的，依 Bot 分好，有縮圖。
- **某個 Bot 的檔案**：對話右上的資料夾圖示。預設依「成果／你上傳的／示範教學／從隊友來的」分組，也可以照資料夾瀏覽。點檔案在右邊預覽（手機從底部拉出）。

## 預覽

| 檔案 | 怎麼看 |
|---|---|
| 文字、Markdown、程式碼 | 直接看（大檔只看前面一段） |
| 圖片 | 直接看 |
| CSV、Excel（.xlsx） | 表格，大檔只看前 1,000 列、100 欄 |
| PDF | 用瀏覽器內建的檢視器 |
| Word、PowerPoint 等 | 只能下載 |
| 壓縮檔 | 列出裡面的檔案 |

## 上傳

在 Bot 的檔案頁按上傳，或把檔案拖進去。預設放到 `/workspace/uploads`，同名會自動加 (2)、(3)。

在對話裡也能直接附檔：輸入框左邊的 ＋、把檔案拖進對話，或貼上截圖。一樣放到 `/workspace/uploads`，送出時訊息附上路徑。

- 一個檔案最多 50 MB（圖片 20 MB）。
- 一次最多 10 個，合計 200 MB。
- 手機可以從其他 App「分享」給 XBot，選一個 Bot 收。
- **你傳的檔案放 30 天後會自動刪掉**（每天清一次）。要留著的，請 Bot 搬到 `uploads` 以外的資料夾。Bot 做出來的成果不會自動刪。見 [儲存空間與例行清理](05-computer.md#儲存空間與例行清理)。

## 其他操作

- 建資料夾、搬移、改名。
- **傳給另一個 Bot**：複製一份過去，放在它的「從隊友來的」。
- **刪除**：要你在「待我處理」允許。
- 下載：每個檔案都有下載鈕。

## Bot 看得到誰的檔案

每個 Bot 只看得到自己電腦裡的檔案。有團隊管理權限的主管 Bot 另外看得到向它報告的 Bot（直屬或間接）的檔案，方便檢查成果；只能列出、預覽，不能改、搬或刪。要把檔案交給別的 Bot，用傳話附上路徑，或上面的「傳給另一個 Bot」。

## 電腦休眠時

照資料夾瀏覽要電腦開著；休眠時會顯示「電腦沒開機」，可以叫醒它再看（指令列加 `--wake`）。預覽、下載、上傳、搬移、刪除在電腦休眠時也能做。

## 指令列

```bash
xbot files list     --bot_id <id> --path /workspace
xbot files read     --bot_id <id> --path /workspace/report.md
xbot files download --bot_id <id> --path /workspace/report.xlsx     # 回傳下載網址
```

大檔上傳用 HTTP：`POST /api/v1/files.upload?bot_id=…&dir=…`（multipart，欄位 `file`）。
