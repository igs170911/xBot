# XBot v1.0 版本說明

> 2026-10。範圍：M0～M3 的任務卡（含 E31 更多引擎），加上 v1.0 的匯入。E32（語音）、v1.0 效能與無障礙正在另外合併，合併後再補進這份說明。
> 每張卡的細節與差異見 [PROGRESS-IMPL.md](PROGRESS-IMPL.md)。

## 這一版有什麼

**安裝與營運**

- `make` 一個入口：`make setup` 自動補工具、`make install` 一鍵裝成開機自動啟動的服務、`make update` 自動備份並在失敗時換回舊版、`make backup`／`restore`、`make deploy` 部署到另一台、`make doctor` 告訴你缺什麼怎麼修。
- 單一執行檔（前端內嵌），amd64 與 arm64。
- 服務預設聽 `0.0.0.0:8780`，區網其他裝置用登入碼連；本機不用登入。

**Bot 與對話**

- 像通訊軟體的介面：Bot 清單、對話串、即時回覆、工作步驟、Markdown。
- 四段權限等級（先問我／一般的事自己做／放手做／完全放手），新 Bot 一律先問我。
- 任務完成判定（完成、要人、交回、只承諾沒做、卡住）、自動續做 2 次、看門狗 15／40 分鐘、供應商錯誤自動重試。
- Bot 設定四頁、外觀（10 種形狀、只有眼睛的頭像、上傳頭像）、`.xbot` 分享與匯入。
- 首次設定兩步、導覽、Bot 範本。

**待我處理**

- 所有要你決定的事集中一處：允許、提問、密碼、接手、核定、確認定時任務、花費上限。10 分鐘內可以復原。
- 代為核准的授權機制（類別、每日次數與金額、期限）。

**Bot 的電腦**

- 每個 Bot 一個強化過的 Docker 容器：唯讀根目錄、無特權、無 sudo、只能上網（連不到主機、區網、tailnet、彼此）。
- 即時看畫面（預設唯讀）、接手與交還、辦公室總覽。
- 閒置 30 分鐘休眠、有工作自動開機。
- 教它一件事：示範一次，整理成技能。
- 搬家（換主機，資料與登入跟著走、逐檔驗證）、從家裡出去（Tailscale exit node）。

**雲端主機**

- `make host-add` 一行把 VPS 加成 Bot 電腦主機：裝 Docker、Tailscale、建帳號、設 sshd、傳映像。只用一條 SSH 連線，不開公開埠。
- 斷線自動接回、離線時工作排隊、主機金鑰固定。

**團隊合作**

- Bot 之間傳話、交辦、回報，有固定的迴圈與成本防護（6 次往來、群組 4 輪、12,000 字…）。
- 群組（2～10 個 Bot、四種回應規則、公告）。
- 團隊（範本、主管、匯報線、團隊地圖、組織架構）、提案與討論、「只有你能決定的事」。

**其他功能**

- 定時任務：一句話建立、八種排程、目標型、補跑一次、行事曆；網址觸發（Webhook）。
- 檔案：依 Bot 分組、預覽（文字、圖片、CSV、Excel、PDF、壓縮檔）、上傳、傳給其他 Bot。
- 技能（自寫、示範、Bot 提議、匯入、共用技能庫）與記憶（兩份清單、可復原）。
- 連接應用程式：60 多個 MCP 服務目錄、OAuth 在服務端完成、權杖不進 Bot 電腦、自訂 MCP、網站登入分享。
- 模型：40 多個供應商範本、自動探測、備援模型、ChatGPT 方案登入、OpenCode Go；用量、價目表、每 Bot／每供應商／全部的花費上限。
- 快判：便宜快速的判斷模型，影子模式、逐用途開關、只會更嚴。
- 引擎：Hermes（預設）、Claude Code、Codex、Gemini CLI、OpenCode、Grok（用你的訂閱，逐 Bot 同意）。額度用完、限速、登入過期時出「額度用完」卡，一鍵換引擎或模型並重送。
- 手機 PWA：21 個手機畫面、裝到主畫面、推播、掃 QR 登入、Android 分享。
- 內建 Tailscale（正式 HTTPS），外部入口（Funnel 或反向代理）只開三條路徑。
- MCP 優先：所有功能都是操作，同時有網頁 API、MCP 工具、`xbot` 指令；代理配對、權限範圍、稽核。
- 從 LazyBoy、OpenMausBot 匯入（只讀來源、可重跑、不重複）。

## 使用者做過的決定

| 決定 | 結果 |
|---|---|
| 安裝位置 | 家目錄（`~/.local/bin`、`~/.local/share/xbot`）、systemd 使用者服務，不用 sudo |
| 開機自動啟動 | 安裝時詢問是否開 linger |
| Node 版本 | 維持 Node 26 |
| 服務聽哪裡（2026-10-18） | 預設 `0.0.0.0`，區網可連；非本機連線一律要登入碼；`XBOT_BIND=127.0.0.1` 只限本機 |
| 快判模型（2026-10-18） | 預設 OpenCode Go 的 `deepseek-v4.1-flash`（Go 沒有 Jev 類模型；實測約 2 秒）。要用 Jev 需在 Zen 儲值 |
| ChatGPT 方案（2026-10-18） | 經 Hermes 正式使用，拿掉「實驗性」與強制勾選，保留條款風險說明 |
| 訂閱憑證（2026-10-18） | 先不放進 Bot 電腦真跑；同意勾選**預設不勾**，逐 Bot 明確同意 |
| 開發埠 | `make dev` 用 8782／5181（避開本機其他專案） |
| 權限等級名稱 | 先問我／一般的事自己做／放手做／完全放手 |

## 已知限制

### 安裝、升級、備份

- `make backup` **不含 Bot 電腦的資料**（家目錄、工作資料夾、Hermes、瀏覽器登入的 Docker volume）；`INCLUDE_LOGINS` 指的舊路徑已不存在。要另外備份 volume，見 [管理手冊](ADMIN.md#備份)。
- `make update` 換回舊版時只換執行檔，不還原資料庫；新版已套用 migration 時舊版會拒絕啟動，要手動 `make restore`。
- `make update` 用當下的環境變數重寫服務檔，安裝時設的 `XBOT_BIND` 等沒帶就會被改回預設。
- `make update` 不重建 Bot 電腦映像；「更新電腦」目前只有指令列（`xbot computers update`），網頁沒有按鈕。
- `make deploy` 不傳 Bot 電腦映像。
- `make up`（docker compose）還不能開 Bot 的電腦，只適合看網頁。
- 網頁的「備份與更新」「成員與紀錄」頁還是佔位。
- 只支援 Linux。rootless Docker 不支援（網路防護套不上，電腦不開機；`make doctor` 還沒提示）。

### Bot 的電腦與主機

- 網頁上只有「叫醒」；休眠、重開、重建、刪除電腦資料、私有網路白名單只能用指令列。
- 只支援 IPv4。同一台 Docker 上有好幾個 XBot（開發版、測試）時共用同一組防火牆規則。
- 本機有 ufw 時無法證明是守門容器擋下的（測試限制）。
- 忙碌的 Bot 會拒絕休眠、重開、示範（不排隊）；搬家中送來的新工作直接失敗。
- 「從家裡出去」與內建 Tailscale、Funnel 都沒有用真的 Tailscale 帳號測過（沒有 auth key）。
- 遠端主機：斷線瞬間的模型請求會失敗；sshd 設定是全域而非只對 `xbot` 帳號；映像過期不會自動更新；Docker ≥ 26 是硬性要求。
- 看門狗放棄後，Hermes 遲到的事件可能落到下一輪；Hermes 自己開的背景回合還沒收成工作。
- Bot 設定裡「在哪裡跑」的說明還寫著「換主機要等之後的版本」，實際上搬家已經可以用（在電腦面板）。

### 對話與核准

- 對話輸入框沒有附檔按鈕，檔案要從 Bot 的檔案頁上傳。
- 代為核准的機制完成，但還沒有操作標上類別，實際上沒有卡片能被代為核准。
- 改權限等級、改團隊或匯報線、換模型供應商，要重開 Bot 的電腦才生效。
- 對話串不能重新命名、釘選、刪除（還沒有對應的操作）。
- 代理能不能核准自己提出的請求（目前可以）、代理能不能接手畫面（有 operate 就可以）待決定。
- 外部代理送的訊息是否算「無人值守」（影響提問 10 分鐘過期）待決定。

### 模型、引擎、快判

- 訂閱引擎（Claude Code、Codex、Gemini CLI、OpenCode、Grok）沒有用真的訂閱跑過完整任務；主機與容器共用 refresh token 可能互相踢掉，CLI 自己換權杖時會碰到唯讀憑證；Codex 的沙箱模式在強化容器內可能不能用。
- Gemini 登入失效時會卡在等登入碼，約 60 秒後才報未登入。
- 首次設定只列出 Claude Code、Codex；「額度用完」卡換的是整個 Bot 的引擎。
- Hermes 以外的引擎不讀 XBot 的技能與記憶。
- ChatGPT 方案的 Bot 建議關掉 Hermes 的 tool_search，還沒自動處理；重新登入的卡片未做。
- 除了 Claude 外，內建價格表待核對；花費日界線的時區、80% 預警未做。
- 快判有 6 個用途只留了掛勾（對話分流、要不要找你核定、是不是問進度、錯誤分類、重複技能、隊友訊息要不要回）。
- 工作鏈的 token 預算暫定 200 萬。

### 其他

- 推播的 VAPID 聯絡方式預設 `mailto:xbot@localhost`，iPhone 可能要改成真的 email。手機沒有獨立的裝置權杖與裝置清單；配對碼存在記憶體（重啟失效）。
- 區網 `http://` 下 PWA、推播不能用（瀏覽器規定），要走 Tailscale https。
- 登出無法逐一撤銷 session；換登入碼會讓所有裝置登出。
- 連接應用程式：Google 還沒放進目錄；中斷連線時不會呼叫供應商撤銷權杖；密碼庫、TOTP 未做；Webhook 金鑰沒有加密存放。
- 定時任務：上一輪還在跑就跳過（LazyBoy 是排隊）；「保持開機」開關、觸發句型建構器未做。
- 團隊：ICS 行事曆、每週學習、團隊記憶、提案的復原未做；議程每 30 秒檢查一次。
- 檔案：資料分頁（SQL）未做；Bot 產生的 HTML 沒有沙箱預覽。
- 教學：Bot 忙碌時不能開始（不排隊）；技能頁還沒有「教的」標籤。
- 匯入：管理權限不帶；OpenMausBot 時區假設台北；OpenMausBot 桌面版金鑰讀不到。
- 記憶寫入沒有 Hermes 的檔案鎖（極小機率覆蓋）。
- §12「每 Bot 進行中對話 3」在 LazyBoy 程式裡沒有，未實作。

## 升級注意

從開發版升到 v1.0：`make update` 會自動套用 migration（到 0025）。E31 改了 Bot 電腦映像（加了 Gemini CLI、OpenCode），所以之後一定要 `make box`，再執行 `xbot computers update`，讓所有 Bot 電腦換上最新映像與安全設定。
