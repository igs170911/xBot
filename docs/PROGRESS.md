## 技術方向（2026-10-18 決定，仍在文件階段）
- 後端 Go、前端 React＋TypeScript；不 fork OpenMausBot，只當功能參考；LazyBoy box 映像沿用。
- 引擎：Hermes 驅動（JSON-RPC，預設）＋ ACP 驅動（Claude Code、Codex CLI…）；XBot 不自己寫 harness。
- 訂閱 CLI 採方案 A：跑在 Bot 容器內，憑證逐 Bot 同意後唯讀掛載；Claude 訂閱只經 Claude Code。
- 寫在 PRD §9、§13、EN-2a/2b/2c、SEC-5、§14，以及 `docs/TECH-DESIGN.md`。

- 實作計畫 `docs/PLAN.md`（M0–M3 任務卡、4 條平行線、關卡驗收）與 `AGENTS.md`（Agent 工作守則）已寫好，可開始派工。
