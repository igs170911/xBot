# CP3＋CP4：M1 一個 Bot＋自己的電腦（關卡 G1）

> 依使用者「放手做」的指示，檢查點不停下等待；報告與 tag（`cp3`、`cp4`）隨時可查。

## 1. 示範步驟

```bash
make box && make test-docker        # 本機＋模擬遠端主機（DinD＋sshd）的完整流程
make dev                            # http://localhost:5181
```
手動試：設定 → 電腦與裝置 → 新增主機（3 步）→ 建 Bot 放到那台 → 對話 → 右上「電腦」看畫面 → 「接手」→ 操作後「交還」並留一句話 → Bot 接著做。

## 4. 安全相關重點（請你看一下）

- Bot 電腦：唯讀根目錄、以 1000:1000 執行、零 capability、無 sudo。
- 網路：Bot 連不到你的主機、家裡網段、Tailscale 網段與彼此；只能上網（失敗就拒絕開機）。
- 金鑰：API 金鑰與 OAuth 權杖只在 Model Proxy；唯一例外是你逐 Bot 同意的訂閱憑證。
- 「完全放手」也不會跳過危險動作的審查（SEC-2，已修正並加測試）。
- 看畫面預設唯讀，由伺服器端過濾鍵盤滑鼠訊息。
