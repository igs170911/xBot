# CP5＋CP6：M2 Bot 互聊與團隊（關卡 G2）

> 依使用者「放手做」的指示，檢查點不停下等待；報告與 tag（`cp5`、`cp6`）隨時可查。

## 1. 示範步驟

```bash
mise exec -- go test -run G2 -v ./internal/collab/ ./internal/org/   # G2 情境測試（真 runtime＋假 Hermes）
make dev   # 開 http://localhost:5181 → 側欄「群組對話」建群組、「建立團隊」套範本
```

手動試：建 3 個 Bot → 建群組（2–10 位）→ 在群組裡交代工作 → 看它們互相 @、到第 4 輪停下；你插話會立刻插隊。

## 3. 順便修掉的問題

- LazyBoy 也有的 bug：Bot 轉派工作時把「已派工」當成答案回報（X02 修正）。
- 「只承諾沒做」的隊友請求不再算已回答（X04）。
- 3 個偶發失敗的測試（其中 2 個是真的產品 bug）。

## 4. 和規格不一樣、需要你決定的事（不急，預設照目前做法）

1. 工作鏈 token 預算暫定 200 萬（PRD 沒寫數字）。
2. 1:1 對話裡你的訊息只「排第一」，不打斷 Bot 間的工作（打斷會讓請求者拿不到答案）。
3. 群組裡 Bot 的回覆不限長度（照 LazyBoy）。
4. 改團隊或匯報線後，執行中的 Bot 要重開才會吃到新的提示。
5. §12「每 Bot 進行中對話 3」在 LazyBoy 程式裡找不到，沒有實作。
