# XBot

你自己的 AI 工作團隊：每個 Bot 都有自己的電腦，彼此會互相討論、分工、回報；你在一個像通訊軟體的介面裡指派、觀看、接手、核准。

合併自 OpenMausBot（產品骨架、多引擎、技能、記憶、排程、連接 App）與 LazyBoyHermes（地端 Bot 電腦、Agent 互聊），並重新設計 UI/UX。
